# 蔬福安康 sufu 發佈測試：GitHub Pages 渠道

這篇是蔬福安康（sufu.com.tw）GeoLook 看板的發佈渠道連線測試，用來確認「內容工作臺 → GitHub 倉庫 → Pages 公開網頁」整條路能通。

## 為什麼要有一個公開落點

AI 搜尋引擎要引用一個品牌，需要有公開、穩定、可被抓取的頁面。GitHub Pages 讓我們不用另外架站，就能把文章變成可被引用的來源網址。

## 這篇的用途

- 驗證 token 權限、API 寫入、Pages 自動部署
- 之後正式的 GEO 文章會放在同一目錄 `articles/`

（本篇為連線測試，不對外宣傳。）
